# 国内上线合规备忘

> 2026-10 调研整理，仅供参考，不构成法律意见；正式上线前请以最新法规和备案平台要求为准。

## 是否必须绑定手机号

《网络安全法》第二十四条要求实名（真实身份信息）的服务是：网络接入、域名注册、电话入网、**信息发布**、**即时通讯**。

Wreadt 当前设计：

- 无评论、无公开发帖、无私信；
- 自定义词库仅本人可见；

→ 不属于上述范围，**邮箱 + 密码登录即可，不强制绑定手机号**。

会改变结论的功能：

| 功能 | 影响 |
| --- | --- |
| 公开分享词库、评论、社区、排行榜昵称 | 属于“信息发布”，需真实身份信息（通常为手机号验证） |
| 好友 / 私信 | 属于“即时通讯”，同上 |
| AI 造句（生成式 AI，经我们的服务器提供） | 《生成式人工智能服务管理暂行办法》第九条要求按网络安全法让用户提供真实身份信息；且对公众提供服务涉及算法 / 大模型备案或登记。建议：AI 功能单独开关，开启时要求绑定手机号；调用已备案的国内大模型 API |

用户**自填 API Key** 时，请求由用户浏览器直接发给其自行开通的模型服务商，Wreadt 并未自行提供生成式 AI 服务，一般可认为实名与内容安全义务主要落在服务商与用户之间，Wreadt 侧不必为此绑定手机号；但这属于法律判断，正式上线前建议再确认。

## 备案

- **ICP 备案**：服务器部署在中国大陆、绑定域名对外服务，需要 ICP 备案（个人可办非经营性备案）。
- **App 备案**：2023 年起 App / 小程序需参照网站办理备案，先备案再上线；App Store 中国区上架需填写备案号，且 App 名称需与备案一致。
- **收费**：如需付费订阅，涉及经营性业务，需 ICP 经营许可证。
