# Wreadt 优化计划

> 2026-10-13 起草。从教育者、产品经理、技术三个视角整理，目标用户为**上班族、有电脑的人、大学生**，并结合**桌面端打字**的特点。
> 本文档同时是进度看板：每完成一项就勾选并在「进度记录」里写一行；需要讨论的问题记在「待讨论」。

## 核心判断

Wreadt 功能已经很全，接下来最值得投入的不是加功能，而是：

1. **少做无用功**：不要让用户从第一个词开始背已经会的词；
2. **把桌面打字的优势用透**：整句听写、字母级错误分析、全局快捷键与悬浮快练；
3. **让学过的词真正用出来**：工作与考试场景中的输出闭环。

## 一、教育者视角

| # | 建议 | 说明 |
| --- | --- | --- |
| E1 | 摸底测试 + “我早就会了” | 首次 3 分钟估出词汇量，跳过已会的词；练习中一键把会的词推到很久以后。收益最大 |
| E2 | 从单词到词块与整句 | 整句听写（听一句、打一句），同时练听力、拼写与语序；重视搭配 |
| E3 | 字母级错误分析 | 统计 ie/ei、双写辅音、-tion/-sion 等易错组合，出针对性练习 |
| E4 | 防止“以为自己会了” | 看答案、用提示、拼写速度更细地影响评分；数据足够后用 FSRS 优化器做个性化参数 |
| E5 | 输出闭环 | 场景题 / 兴趣流里用错的词，自动进入复习或自动 mark |

## 二、产品经理视角

| # | 建议 | 说明 |
| --- | --- | --- |
| P1 | 分人群的新手引导 | 学生：考试 + 日期，倒推每日量；上班族：职业 + 每天几分钟；首页按身份精简 |
| P2 | 习惯养成 | 每日目标、可请假一天的连续打卡、周报；提醒克制 |
| P3 | 考试专项 | 雅思听力拼写、写作同义替换、四六级 / 考研常考搭配 |
| P4 | 商业化分层 | 免费：本地 + 自带 Key；个人付费：同步、服务器 AI 额度、桌面端高级功能；团队付费：企业术语表（最值得验证） |
| P5 | 北极星指标 | “每周用到输出里的词数”（场景题、兴趣流中用对的推荐词） |

## 三、技术视角

| # | 建议 | 说明 |
| --- | --- | --- |
| T1 | Tauri 桌面端 | 全局快捷键摘词（选中即入词库并保留原句）、悬浮小窗快练、托盘显示到期词数、系统级老板键；浏览器插件可先行 |
| T2 | PWA 离线 | 网页可安装、可离线，成本低 |
| T3 | 发音兜底 | 有道接口非正式开放，准备浏览器语音合成或授权 TTS 作为备选 |
| T4 | AI 测试集 | 固定 20 组输入，改提示词后自动检查：题目自洽、方向为中文、推荐词与题目相关、无 Markdown |
| T5 | 合规 | 排行榜、分享、小组等社交功能涉及实名，先看 docs/compliance.md |

## 路线与进度

### 近期（1～2 周）

- [x] **E1 摸底测试**：按词库难度阶梯（高考 → 四级 → 六级 → 考研 / 雅思；N5 → N1）抽词，认识 / 不认识快速判断，混入假词校正“装懂”，估计掌握程度后可一键把已会的词标为已认识（之后偶尔抽查）
- [x] **E1 “我早就会了”**：打字时一键把当前词推到很久以后复习
- [x] **P1 新手引导**（/welcome：身份 → 目标 → 摸底，按身份自动选词库与目标类型）
- [x] **P1 + P2 每日目标与考试倒计时**：设置每日目标与考试日期，倒推每天新词量，首页 / 打字页显示今日完成度
- [x] **T4 AI 测试集**：固定输入 + 自动校验脚本
